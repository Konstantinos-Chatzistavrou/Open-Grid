# Assets that are not in the repo

The repo is public. Assets whose licence does not allow redistributing the source files (Fab, Unreal Marketplace,
anything paid) live in `ue5/Content/ThirdParty/`, which git ignores. Anyone cloning the repo fetches them from the
source below with their own account.

Add a row for every asset you place there:

| Folder in Content/ThirdParty | Asset | Source (URL) | Licence | Used for |
|---|---|---|---|---|
| | | | | |

Assets that may be redistributed (CC0, CC BY with credit, our own) go in the normal `Content/` folders and are
credited in `CREDITS.md`.
