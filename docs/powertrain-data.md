# Powertrain reference data (2026-11-24)

This page records every powertrain value we import, where it comes from, its licence, and how much to trust it.
Nothing here is invented: where only a simplified example map exists, it is labelled as such.

## What was added

| file | contents | source | licence | confidence |
|---|---|---|---|---|
| `data/powertrain/reference-powertrains.json` | 4 full-throttle engine maps (Audi 250 Nm/6500, Sedan 370 Nm/6500, UAZ bus 208 Nm/4000, city bus 1250 Nm/2200) with gear ratios | Project Chrono vehicle JSONs, commit `e166f3e5` | **BSD-3-Clause** | **low-medium** - simplified example maps, **not measured dyno data** |
| `data/powertrain/final-drives.json` | 1,699 real vehicle configurations: axle ratio, gear count, transmission type, displacement, rated hp | US EPA test-car certification CSVs (`data/validation/.cache/epa-2015.csv`, `epa-2016.csv`) | **public domain** (17 USC 105) | **high** - manufacturer-submitted certification data |
| `data/powertrain/source/**` | the exact Chrono JSON files used, unmodified | same commit | BSD-3-Clause (text in `LICENSE-projectchrono.txt`) | - |
| `data/powertrain/MANIFEST.json` | URL + sha256 of every input consumed | - | - | - |

Generated by `node tools/physics/import_powertrain.mjs` (add `--fetch` to re-download the pinned Chrono sources).
Checked by `node tools/physics/check_powertrain.mjs`.

## Why these sources, and why not the others

**Chrono (BSD-3) is the only permissively licensed source of complete engine maps found in this pass.** Its
"SimpleMap"/"EngineSimpleMap" data is *reference* data: flat-topped torque plateaus (250 Nm from 1500-3500 rpm on
the Audi, 370 Nm on the sedan) that are clearly simplified, so the importer records
`confidence: low-medium ... NOT measured dyno data` on every entry. They are useful as a coherent, legal sanity
baseline and for scaling studies, not as a claim about a specific production engine.

**EPA certification CSVs are public domain and are real measured/declared vehicle data** (axle ratio, gear count,
transmission type, displacement, rated power). This is the accurate half of the delivery.

## Gear ratio convention (important)

Chrono's `ManualTransmissionShafts` / `AutomaticTransmissionSimpleMap` gearboxes store **shaft speed ratios**
(out/in): they ascend from a low gear (Audi 0.294) to an overdrive (1.516). Conventional gear ratios descend from
> 1. The importer detects the ascending convention and inverts (`1 / r`), storing conventional values
(Audi: 3.40 / 2.75 / 1.77 / 0.93 / 0.70 / 0.66). The convention used is recorded per entry in
`drivetrain.ratio_convention`.

## Final drives

Axle ratios come straight from EPA rows (e.g. 2015 Chevrolet Camaro, automatic, 6 gears, 3.6 L, 304 hp,
final drive **2.92**). They are real production configurations and can be used as class proxies for fictional cars
with the citation intact; `final-drives.json` intentionally does not claim which fictional car should use which.

## Gaps (not filled, deliberately)

- **Measured full-load torque curves under a permissive licence**: none found that we can redistribute. SAE/Elsevier
  papers, FSAE TTC, Calspan and commercial simulator data are all excluded by licence; manufacturer charts are
  copyrighted (peak figures are facts, but copying curves is not). We did not synthesise a curve and call it measured.
- **Fuel-consumption / BSFC maps**: no openly licensed measured maps found.
- **Torque converter characteristics**: not present in the accepted sources.
- **Thermal derating**: not present.

## Rejected sources

| source | reason |
|---|---|
| SAE Technical Papers (torque/BSFC tables) | paywalled, redistribution forbidden |
| FSAE TTC / Calspan / TIRF | membership/confidential |
| CarMaker / Adams / Simulink Powertrain Blockset examples | commercial EULA |
| OptimumG / commercial sim data | proprietary |
| Manufacturer brochure/press curves | charts are copyrighted; only isolated facts may be cited |
| GitHub repos without a licence (several "dyno graph" projects) | no license = all rights reserved |
| OpenF1 / FastF1 telemetry | not powertrain data; FOM rights / NC-SA terms |

## Reproduce

```bash
node tools/physics/import_powertrain.mjs --fetch   # Chrono JSON at the pinned commit + EPA cache
node tools/physics/check_powertrain.mjs            # sanity report
```
