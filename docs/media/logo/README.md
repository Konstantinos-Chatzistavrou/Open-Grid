# Logo files

| file | use |
|---|---|
| `open-grid-logo.svg` | full logo (letters + wordmark) on a dark square, for social avatars |
| `open-grid-logo-transparent.svg` | full logo, no background, white parts: dark backgrounds only |
| `open-grid-logo-light.svg` | full logo, no background, dark parts: light backgrounds |
| `og-mark.svg`, `og-mark-light.svg` | the two letters only, tightly cropped, for dark / light backgrounds |
| `og-icon.svg` | the two letters on the dark app-icon square |

Colours: `#0A0A0A` black, `#FFFFFF` white, `#FF1111` red. The Open Grid name and logo are not covered by the code or
art licences; see "Name and logo" in `../../../LICENSING.md`.
