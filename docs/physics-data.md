# Physics validation data (legal sources)

Data used to validate the vehicle physics, with licence and provenance. Nothing here is scraped
from a proprietary source, and every file records where it came from.

## EPA coast-down / road-load — public domain

- **File**: `data/validation/epa_coastdown.json` (2,816 vehicles, MY2015–MY2016)
- **Licence**: US Government work, **public domain** (17 U.S.C. §105) — see `data/validation/LICENSE-epa.txt`.
- **Source**: US EPA *Test Car List Data* ("Data on Cars used for Testing Fuel Economy")
  <https://www.epa.gov/compliance-and-fuel-economy-data/data-cars-used-testing-fuel-economy>
  MY2015: `15tstcar.csv`, MY2016: `16tstcar.csv`
- **Standard**: SAE J2263 / 40 CFR 1066.310 road-load:
  `F(v) = A + B·v + C·v²` [lbf, mph]
- **Generated by** `tools/physics/import_epa_coastdown.mjs` (downloads into a git-ignored cache,
  de-duplicates by test vehicle + configuration, prefers measured "Set" coefficients over "Target",
  drops placeholder rows such as A=B=C=1 and physically impossible ranges).
- **Fields kept**: model year, make, model, test id, configuration, rated hp, drive, transmission,
  equivalent test weight (lb → kg), the published imperial A/B/C verbatim, and the SI derivatives
  `F0 [N]`, `F1 [N/(m/s)]`, `F2 [N/(m/s)²]` using exact NIST/SAE factors.

### What the tests prove

`packages/vehicle-physics/test/epa-coastdown.test.mjs` (runs in CI via `npm test`):

1. **Provenance/sanity** — licence is public domain, >1,000 vehicles, coefficients positive,
   masses 600–4,500 kg.
2. **Conversion** — every row's SI coefficients match the imperial values to <0.02 N / <0.05 / <0.01.
3. **Road-load form** — power rises monotonically 30→90 mph for every vehicle and stays in a
   physical band.
4. **Engine vs real data** — a neutral coast-down of the actual WASM core for 8 vehicles spanning
   the mass range (BMW i3 → Maybach S 600): the fitted aerodynamic slope `dF/d(v²)` is compared
   with the EPA `F2`. Observed error: **1.2 % – 8.1 %** (tolerance 25 %).

The last test is the important one: it parameterises a real car (mass = EPA ETW, `CdA = 2·F2/ρ`)
and checks the engine reproduces the published drag, not just that a constant is copied.

## Regenerating

```bash
node tools/physics/import_epa_coastdown.mjs     # downloads EPA CSVs, rewrites the JSON
cd packages/vehicle-physics && npm test          # runs the validation
```
